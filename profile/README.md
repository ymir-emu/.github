Ymir is a work-in-progress Sega Saturn emulator for Windows, macOS, Linux, and FreeBSD (x86_64 and ARM64).

## Overview & Features

- Support for MAME CHD, BIN+CUE, IMG+CCD, MDF+MDS, and ISO disc images
- Auto IPL (BIOS) ROM detection and automatic region switching
- Local 2-player support with customizable controls
- Internal, DRAM, and backup RAM cartridge management with import/export tools
- Save states, rewinding (up to 60s), turbo, and frame stepping
- VRR fullscreen support, deinterlaced/progressive rendering options, and transparent mesh polygon rendering
- Built-in feature-rich debugger
